## English

The official website of **NUThon**, the hackathon of the Deanship of Student Affairs at Najran University (450+ students in 104 teams, 2026). I co-founded the hackathon, led its technical team, and designed and built this website as the main hub for participants.

### Features

- Arabic, right-to-left single-page site, responsive, with a mobile menu
- Registration countdown and registration statistics by track
- Tracks, prizes, judging criteria and the seven-phase timeline
- Workshop cards that update their status by date (coming soon, join now, ended) and show the recording link after each workshop ends
- Terms and conditions, organizers and partners, and an FAQ
- Dark mode that follows the device setting and remembers the visitor's choice
- Links to the registration form, the participant guide (PDF) and the project presentation template (PPTX)

### Built with

HTML · Tailwind CSS · JavaScript · Lucide icons · GitHub Pages

### Repository structure

- `index.html`: the whole site, on one page
- `assets/images/`: NUThon logos, partner logos, favicons and the hero background
- `assets/docs/`: the participant guide (PDF) and the project presentation template (PPTX)

### Run locally

Open `index.html` in a browser. No build step is needed.

## العربية

الموقع الرسمي لهاكاثون **إنيوثون** التابع لعمادة شؤون الطلاب بجامعة نجران (أكثر من 450 طالباً وطالبة في 104 فرق، 2026). شاركت في تأسيس الهاكاثون وقدت فريقه التقني، وصممت هذا الموقع وبنيته ليكون المرجع الرئيسي للمشاركين.

### المميزات

- موقع عربي من صفحة واحدة باتجاه من اليمين لليسار، متجاوب مع الجوال وفيه قائمة خاصة بالجوال
- عداد تنازلي لنهاية التسجيل، وإحصائيات التسجيل حسب المسار
- المسارات والجوائز ومعايير التحكيم والبرنامج الزمني بمراحله السبع
- بطاقات لورش العمل تتغير حالتها تلقائياً حسب التاريخ (قريباً، انضم الآن، انتهت)، وتعرض رابط التسجيل المرئي بعد انتهاء الورشة
- الشروط والأحكام، والجهات المنفذة والشركاء، والأسئلة الشائعة
- وضع داكن يتبع إعدادات الجهاز ويحفظ اختيار الزائر
- روابط نموذج التسجيل ودليل المشاركة (PDF) وقالب عرض المشاريع (PPTX)

### التقنيات

HTML · Tailwind CSS · JavaScript · Lucide · GitHub Pages

### محتوى المستودع

- `index.html`: الموقع كامل في صفحة واحدة
- `assets/images/`: شعارات إنيوثون وشعارات الشركاء والأيقونات وصورة الخلفية
- `assets/docs/`: دليل المشاركة (PDF) وقالب عرض المشاريع (PPTX)

### التشغيل على جهازك

افتح ملف `index.html` في المتصفح، ولا يحتاج أي خطوات بناء.
